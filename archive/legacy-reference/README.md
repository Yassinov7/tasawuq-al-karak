# أرشيف مرجعي قابل للحذف لاحقًا

هذه الملفات من مرحلة التأسيس/الماليات/تصميم الانضمام السابقة. ليست تعليمات عمل، ولا وثائق نشر نشطة، ولا كودًا يستورده التطبيق أو الاختبارات الحالية.

المرجع الحالي: [شروط البناء](../../PROJECT_RULES.md)، [المتابعة](../../WORK_PROGRESS.md)، [الخطة](../../docs/implementation-master-plan.ar.md).

المحتويات:

- `AGENTS.foundation-era.md.txt`: نسخة تعليمات مرحلة التأسيس قبل تحديثها.
- `docs/finance-c*`: تصميم وتقارير C2–C12 السابقة، للرجوع الهندسي فقط، وليست خطة النظام المالي الجديد.
- `docs/subscriptions/`: تصميمات الاشتراكات والائتمان والماليات والترحيلات التجريبية التاريخية.
- `docs/ui/` وتقارير تدفقات العميل والأدوار والسائق: تصورات سابقة قد لا تعكس النسخة الحالية.
- `source/`: شاشة الترحيب القديمة، ومحرك ومسودة انضمام التاجر القديمين، ونافذة مغادرة لم يعد لها مستهلك. امتداد `.txt` يخرجها من البناء والفحص.
- `tests/`: اختبار محرك المسودات القديم؛ أُحيل للتاريخ بعد استبدال تدفق الانضمام، ولم تُنقل اختبارات السلوك التشغيلي المطلوب.
- `MANIFEST.json`: فهرس المصدر والوجهة وسبب الأرشفة.

حفظت البنية الداخلية للوثائق قدر الإمكان. روابطها التاريخية إلى ملفات خارج الأرشيف قد تشير إلى مواقعها القديمة؛ ليست عقودًا نافذة. لا تنسخ أوامر تشغيلها إلى القاعدة الجديدة.

يمكن حذف هذا المجلد لاحقًا بعد مراجعة المالك. لا يحتوي حزمة migrations الفعالة ولا يثبت إزالة الماليات السابقة من قاعدة البيانات أو من التطبيق؛ ذلك له دفعات الاستبدال المحددة في المتابعة.

- customer-home/: مقدمة رئيسية العميل والترويج الثابت السابقان. استبدلهما مسار /home بتصميم RUI-CUS-01، ولا مستهلك تشغيلي لهما.
