# تدقيق الحالة الحالية

## مؤكد محليًا

- `subscription_plans` تحفظ الاسم والمدة والسعر والعملة والوصف و`is_active`.
- طلب التاجر يلتقط لقطة للخطة في `merchant_applications`.
- قبول الإدارة عبر `review_merchant_application` ينشئ التاجر والمتجر وفترة في `merchant_subscriptions` من `now()` إلى `now() + duration_months`.
- Migration الإصلاح `202610010007_fix_order_cancellation_and_merchant_wallet.sql` تجعل المحفظة تبدأ برصيد صفر؛ سعر الاشتراك ليس إيداعًا بالمحفظة.
- `wallet_transactions` هي سجل الحركات، ويطبق Trigger الرصيد ويمنع السالب.
- لا توجد محليًا فواتير، دفعات، تجديدات، عمولات، أو تسويات مرتبطة بالطلبات.

## فجوات مؤكدة

- انتهاء الاشتراك لا يقيّد ظهور المتجر أو طلباته أو منتجاته في الكود/SQL المحلي.
- لا يوجد إثبات دفع أو حالة دفع أو تجديد أو فترة سماح.
- لا يجوز افتراض تطابق قاعدة الإنتاج مع الـmigrations المحلية.
