# التدفقات المالية المقترحة

1. قبول التاجر: فترة اشتراك + فاتورة رسوم أولى + قيد دفتر «مستحق اشتراك»؛ لا دفعة.
2. تسجيل دفعة الإدارة: قفل الفاتورة، التحقق من العملة والمبلغ والمفتاح المتكرر، إنشاء الدفعة والتوزيع وقيدين متوازنين، ثم تحديث حالة الفاتورة داخل Transaction واحدة.
3. تسليم `store_order`: يحسب أساس العمولة من لقطة قيم عناصر الطلب، ينشئ عمولة واحدة فقط وقيد استحقاق للمنصة.
4. التسوية: عملية صريحة تربط القيود المتقابلة؛ لا تخصم تلقائيًا من محفظة أو مستحقات تاجر.

المحفظة الحالية تبقى رصيدًا تشغيليًا منفصلًا. لا تُستخدم مصدرًا للدين أو الدفع إلا بقرار مستقل وتحويل دفتر موثق.
