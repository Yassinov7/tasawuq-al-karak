# مرجع الماليات المستبدلة

هذه ملفات قديمة للمراجعة فقط، استبدلتها دفعة invoice-finance. لا تستورد من التطبيق ولا تدخل في TypeScript أو Lint، ولا تشغل اختبارات أو SQL هذا المجلد على النظام الجديد. يمكن حذف المجلد كاملًا؛ لا يعتمد عليه البناء أو الاختبار الحالي.

الفهرس: manifest.json. يحتفظ بتاريخ الترحيلات المطبقة في supabase/migrations خارج الأرشيف، ويتبعها ترحيل الاستبدال. المرجع التنفيذي الجديد: docs/invoice-finance-test-plan.ar.md من جذر المشروع.
