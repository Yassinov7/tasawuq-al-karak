3. قبول مجموعة محدودة من العمليات الجديدة ومراقبة المطابقة بعد كل دورة كاملة. لا تحويل طلب legacy قائم أو فترة مدفوعة إلى الكاتب الجديد تلقائيًا.
4. عند مشكلة: إيقاف قبول المجموعات الجديدة، مع الحفاظ على استكمال واستعادة C4/C8 المسجلة. لا تبديل كاتبها ولا حذف أو عكس قيود تلقائي. أي تصحيح محاسبي قرار مستقل.

**القرار المحدّث: BLOCKED — VALIDATION PENDING.** التطبيق البنيوي مثبت بتأكيد المالك فقط؛ نتائج حزمة القراءة والاختبارات السلوكية لازمة قبل READY FOR CONTROLLED ACTIVATION. الأدوات السلوكية الحالية محلية loopback ولا تُوجَّه للمشروع المستضاف بتجاوز حراسها. لا اختبارات كتابة دون موافقة مستقلة.
