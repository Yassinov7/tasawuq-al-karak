# RUI-CUS-15 — حساب العميل

الحالة: **مكتملة برمجيًا — بانتظار اختبار الهاتف وقبول المالك**.

## المسار والغرض

- المسار `/home/account` والملف `src/app/(customer)/home/account.tsx`، وهو تبويب «حسابي» المباشر ضمن تبويبات العميل الأربعة.
- الصفحة مركز وصول لخدمات العميل وليست نسخة من حساب التاجر أو السائق؛ تشترك معهما في لغة العرض ومكونات الحساب فقط.

## التنظيم المعتمد للتجربة

- ترويسة واحدة بلا زر رجوع، مع إبقاء وصول العميل إلى السلة كما كان.
- ملف شخصي مدمج يعرض الاسم والبريد الحقيقيين وشارة الدور، مع انتقال مباشر إلى المعلومات الشخصية.
- مجموعة «مشترياتي»: الطلبات، الفواتير، العناوين، والمفضلة.
- مجموعة «إدارة الحساب»: المعلومات الشخصية، الإشعارات، والإعدادات.
- مجموعة «الخصوصية والأمان»: كلمة المرور، الخصوصية، وشروط الاستخدام، ثم «حول التطبيق» ومعلومات الإصدار وتسجيل الخروج.
- لا عدادات أو معلومات مالية أو وظائف خاصة بالتاجر والسائق، ولا تكرار للإشعارات بين المجموعات.

## البيانات والاستقرار

- تعتمد الهوية على `usePersonalAccount` وبيانات الحساب المصرح بها، وتعزل إعادة تركيب الشاشة بمعرف الحساب عند التبديل.
- تبقى آخر بيانات ملف متاحة أثناء تعذر التحديث، مع رسالة مدمجة وإعادة محاولة، ولا يعاد بناء منطق الحساب أو تسجيل الخروج.
- أزيلت سجلات التطوير `[cart] read` و`[catalog] read` فقط؛ لم تتغير القراءة أو الدمج أو SWR أو Realtime أو التخزين المؤقت.

## اختبار الهاتف المطلوب

- الاسم والبريد وتعديل المعلومات، ثم كل وجهة والرجوع إلى التبويب.
- الفاتح والداكن، RTL، 320 و360 بكسل، الخط المكبر، وشبكة متقطعة.
- تبديل الحساب، ظهور آخر بيانات سليمة أثناء فشل التحديث، وتسجيل الخروج بتأكيد.
- التأكد من بقاء التبويبات: الرئيسية، المتاجر، العروض، حسابي.

لا Migration أو مكتبة جديدة. تبقى الصفحة مفتوحة حتى قبول الهاتف، ولا تبدأ صفحة أخرى.

نجح `npx tsc --noEmit`، ونجح ESLint مرة واحدة للملفات البرمجية الثلاثة المعدلة دون أخطاء. لم تُشغّل بيئة مرئية.
