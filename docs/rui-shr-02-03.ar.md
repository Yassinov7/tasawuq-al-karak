# RUI-SHR-02 وRUI-SHR-03 — الواجهتان الماليتان المشتركتان

الحالة: **الصفحتان مغلقتان بقبول المالك النهائي**. العملة المعتمدة SYP.

- `/financial-invoice` يستخدم القراءة المصرح بها عبر `read_money_invoice`. يختار عرض العميل المعتمد أو مستند التاجر أو عرض السائق والإدارة بعد التحقق من الحساب. غياب المستند ورفض الوصول لهما رسالة واحدة. فشل القراءة المؤقت يبقي بيانات النطاق نفسه ويتيح إعادة المحاولة.
- العناوين تميز الشراء والمبيعات والاشتراك والتحصيل والأجر والتسوية والتصحيح. يظهر تاريخ الاعتماد عند توفره، أو تاريخ الإنشاء. السداد منفصل عن حالة المستند. تعرض المبالغ بوحدة المصدر SYP. تظهر مراجع الطلب والمهمة، وروابط التسوية والتصحيح، وسبب التسوية واتجاهها عند توفرهما. تستخدم إجراءات الإدارة مسارها القائم.
- `/wallet` يعرض فواتير العميل أو مستحقات التاجر واشتراكاته أو تحصيل السائق وأجره أو خزينة الإدارة وأرقام أطرافها. يعرض أحدث ثلاثة مستندات من القراءة ووقت نجاحها. يقود إلى `/invoice` أو `/merchant/finance` أو `/driver/cash-account` أو `/admin/finance`. القراءة معزولة بالحساب ويعاد التحقق عند العودة والتحديث اللحظي.
- المكونات المعاد استخدامها: `AppHeader` و`DocumentReference` و`InvoiceStatus` و`FinancialSection` و`FinancialAmount` و`FinancialFeedback` و`LoadingSkeleton`.

اختبار الهاتف: افتح المدخل بكل دور، وافتح مستندًا وارجع. جرّب رابطًا غير مملوك، وشبكة متقطعة، وتبديل الحساب. راجع مستندًا مصححًا وتسوية قبض وأخرى صرفًا. افحص RTL والثيمين وعرض 320 و360 مع الخط المكبر.
