# مصفوفة الاختبار

- قبول تاجر جديد مرتين: فترة وفاتورة واحدة فقط.
- التجديد التلقائي مع/دون ائتمان، والإيقاف اليدوي، وتغيير الخطة للفترة التالية.
- دفعة كاملة وجزئية ومحاولة إرسال المرجع نفسه مرتين.
- انتهاء الفترة، أيام السماح السبعة، منع الطلبات الجديدة مع استمرار السابقة.
- تسليم `store_order` واحد أو عدة متاجر وتكرار حدث التسليم: عمولة واحدة لكل طلب فرعي.
- رفض/إلغاء قبل التسليم: لا عمولة.
- عملات مختلفة: منع المقاصة أو التحويل الضمني.
- تاجر وعميل وإدارة: تحقق RLS لكل قراءة وكتابة.
- انقطاع شبكة وإعادة محاولة RPC: لا فاتورة أو دفعة أو عمولة مكررة.
