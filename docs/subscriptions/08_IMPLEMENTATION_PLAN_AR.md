# خطة التنفيذ المرحلية

1. اعتماد القرارات: الائتمان، العملة، تاريخ القطع، وسلطة اعتماد الدفعات.
2. Migration تصميمية صغيرة للجداول والقيود والـRLS والـRPCs الأساسية، ثم اختبار SQL.
3. ربط قبول التاجر بإنشاء الفترة والفاتورة ضمن Transaction واحدة.
4. بناء تسجيل الدفعات الإداري والدفتر والتقارير، ثم اختبار التزامن والتصحيح.
5. إضافة احتساب العمولة عند التسليم بعد تثبيت مصدر إجمالي المنتجات في `store_orders`.
6. إضافة فحص صلاحية الاشتراك للسوق والطلبات مع حماية الطلبات السابقة.
7. بناء واجهة التاجر للاشتراك والفواتير بعد استقرار الـRPCs.

لا تبدأ أي مرحلة قبل قبول التصميم وفحص Schema الإنتاج قراءةً فقط.
