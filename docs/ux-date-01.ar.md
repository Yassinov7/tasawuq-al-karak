# UX-DATE-01 — تقويم مواعيد عروض التاجر

الحالة: **منفذ محليًا — بانتظار تجربة الهاتف وقبول المالك**. النطاق محرر عروض التاجر `/merchant/offer-editor`، ضمن RUI-MER-08، وبداية العرض ونهايته فقط. تقرير `arabic-ux-review.ar.md` معتمد وفق إفادة المالك؛ لا يشمل ذلك اعتماد هذا التنفيذ قبل الهاتف.

## التصميم والتنفيذ

- المكوّن الحالي `OfferExpirationPicker` معاد التصميم، ويستخدمه `MerchantOfferForm` مرتين للبداية والنهاية. لا شاشة أو تقويم موازٍ.
- حقل موعد بملخص عربي واضح وعبارة «بتوقيت سوريا · نظام 24 ساعة». يظل خيار «يبدأ الآن» مميزًا عن اختيار بداية مجدولة، وخيار إبقاء الموعد يحفظ القيمة السابقة.
- نافذة تقويم بعنوان وشهر وسنة بالعربية، سهمين للتنقل، وإمكانية الانتقال المباشر للشهر والسنة. يبدأ الأسبوع بالسبت بسبعة أعمدة مع خلايا فارغة مكملة للأسبوع. لليوم الحالي إطار ونقطة، وللمحدد تعبئة دلالية وحالة إتاحة.
- الأيام الماضية أو التي لا تسمح بدقيقة صالحة بعد بداية العرض معطلة. اليوم المشترك مع البداية متاح إذا بقي وقت صالح؛ التحقق النهائي يرفض الدقيقة السابقة أو المساوية للبداية.
- حقلا ساعة ودقيقة بلوحة أرقام، يقبلان الأرقام العربية والفارسية واللاتينية، مع حدود 00–23 و00–59 ورسائل خطأ. لا قائمة ساعات طويلة أو سلاسل ضغط متكررة.
- الملخص يسبق التأكيد. تعديل المسودة داخل النافذة لا يغير النموذج حتى «تأكيد الموعد»؛ «إلغاء» أو رجوع Android يغلقان دون كتابة.
- الأزرار خارج محتوى التمرير، مع مساحة آمنة ولوحة مفاتيح وارتفاع محدود بعرض أقصى 440، وأزرار قابلة للالتفاف. ارتفاع صفوف الأيام مرن. رموز الثيم ومساعدات RTL الحالية دون خاصية `direction` أو انعكاس مزدوج.

## الزمن وعقد الحفظ

`src/lib/offer-syria-time.ts` يستخدم `Intl.DateTimeFormat` والمنطقة المسماة `Asia/Damascus` لا إزاحة ثابتة ولا المنطقة المحلية للجهاز. يحوّل التاريخ والساعة المدخلين إلى UTC، ويتحقق من العودة إلى نفس وقت سوريا، ويرفض أوقات الانتقال التاريخية المفقودة أو المتكررة بدل اختيار لحظة بصمت.

القيم المحفوظة تعرض في توقيت سوريا دون إعادة تفسيرها. اختيار «إبقاء الموعد المحفوظ»، أو تأكيد نفس الدقيقة المحفوظة دون تغييرها، يعيد وضع `keep` ويبقي سلسلة اللحظة الأصلية نفسها بما فيها الإزاحة والثواني وأجزاء الثانية. مواعيد العرض القديم لا تعاد كتابتها لمجرد فتح التقويم أو تغيير عنوان العرض. المواعيد الجديدة فقط تفسر بتوقيت سوريا.

`merchant-offer-editor.ts` يحافظ على أسماء ومعاملات `save_store_offer_v2`. البداية المجدولة يجب أن تكون مستقبلية والنهاية بعد البداية؛ وضع «يبدأ الآن» يبقى مستخدمًا للّحظة الحالية. عند تبديل وضع البداية يشتق `MerchantOfferForm` حد النهاية من الوضع الحالي بدل استخدام `selectedStartInstant` قديم. الخادم يظل صاحب قواعد الأهلية والحفظ.

أكد المالك سابقًا نجاح تطبيق إصلاح `retain_started_offer`. لم يغير هذا التنفيذ الدالة أو ترحيلاتها أو إشعارات العروض أو المهام. دوال الزمن المحلية القديمة باقية لمستهلكيها، ومنها محرر إعلانات الإدارة، دون تغيير سلوكهم. لا مكتبة أو Migration جديدة ولا أي إجراء بعيد.

## الفحوص وحدود الإثبات

- `scripts/test-offer-expiration.cjs`: 13 فحصًا مركزًا للتقويم والتحويل وحدود اليوم/الدقيقة والبداية والنهاية والقيم المحفوظة وعقد v2. تشمل ست مناطق زمنية للجهاز وإثبات UTC موحد، وحدود فبراير، وعبور منتصف الليل، وحالات انتقال الساعة التاريخية في سوريا.
- `scripts/test-offer-date-picker.cjs`: تشغيل المكوّن الفعلي بمهايئات React/Native محلية؛ اختيار يوم معطل/صالح، إدخال الوقت العربي، بنية الأسابيع والأزرار خارج التمرير، تحويل التأكيد، والإلغاء وإبقاء الموعد في حالتي اتجاه النظام. ليس اختبار قياسات أو لوحة مفاتيح أصلية.
- اختبار محرر العروض القائم يحمي التحقق والحفظ واستعادة النتائج المجهولة. عُدّل تطابق نصي هش لقبول تنسيق المصدر الجديد دون تغيير التوقع السلوكي.
- نجحت اختبارات التاريخ الـ13 والمكوّن، و40 اختبارًا قائمًا لمحرر العروض والحفظ. TypeScript ناجح بتشغيل واحد. كشف تشغيل Lint الوحيد ملاحظتي `Date.now()` أثناء التصيير و`__filename` في الاختبار؛ صُححتا باستخدام تهيئة `useState` ومسار صريح، وأعيدت اختبارات التاريخ والمكوّن بنجاح. لم يكرر TypeScript أو Lint احترامًا لطلب المالك، لذلك لا توجد نتيجة Lint ثانية بعد التصحيح.
- لم يشغل Expo أو Metro أو محاكي أو متصفح أو بناء APK. لا ادعاء باختبار هاتف أو قياسات عرض أصلية.

## اختبار الهاتف المطلوب

1. إنشاء عرض يبدأ الآن، ثم عرض مجدول؛ اختيار يوم وشهر وسنة والساعة والدقيقة، ومراجعة الملخص «بتوقيت سوريا» قبل الحفظ.
2. اختبار اليوم الحالي، يوم سابق معطل، نهاية مساوية للبداية أو تسبقها، والانتقال بين آخر شهر وأول السنة والسنة الكبيسة. التأكد من ظهور رسالة مفهومة للوقت غير المسموح.
3. فتح عرض محفوظ ثم الإلغاء أو تأكيد الدقيقة نفسها؛ التأكد من بقاء الموعد وعدم تغيره. تغيير منطقة الجهاز الزمنية والتحقق من بقاء العرض بتوقيت سوريا ومن ثبات اللحظة المحفوظة.
4. تجربة عرض 320 و360، الخط المكبر، الفاتح والداكن، لوحة الأرقام، تمرير التقويم، بقاء التأكيد والإلغاء ظاهرين، ورجوع Android دون فقدان نموذج العرض.
